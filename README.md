# نظام إدارة مركز التدريب المهني (Vocational Training Center Management System)

منظومة برمجية متكاملة واحترافية باللغة العربية (RTL Layout) لإدارة مراكز التدريب والورش المهنية والهندسية وفق معايير التصميم الصناعي الحديث (**Industrial-Modern Aesthetic**)، باستخدام تدرجات الرمادي الأردوازي (Slate Gray)، الكحلي العميق (Deep Navy Blue)، ولمسات الأمان والإنذار باللون البرتقالي/الكهرماني (Safety Amber & Hazard Orange) مع خط **Cairo** المعتمد.

---

## 🚀 التحديثات الرئيسية للتشغيل الفعلي (Production Updates)

### 1. الجاهزية للاستخدام الفعلي والحفظ الدائم للبيانات (Permanent Data Storage)
- **قاعدة البيانات الدائمة على القرص**: يتم حفظ كافة التعديلات، المتدربين الجدد، سجلات الحضور اليومية، والتقييمات العملية بشكل دائم ومباشر في ملف:
  ```
  data/vtc_data.json
  ```
- **المزامنة التلقائية**: يقوم خادم النظام (`server.ps1`) بمعالجة طلبات الحفظ الفوري (`POST /api/save`) وتقديم البيانات الدائمة (`GET /api/data`) مع الحفاظ على مزامنة محلية فورية في المتصفح.
- **النسخ الاحتياطي**: يتوفر خيار تصدير نسخة احتياطية كاملة (JSON Backup) بنقرة زر من لوحة الإدارة.

### 2. تسجيل دخول المستخدمين بكلمة المرور (User Password Login)
- تم تزويد **المتدربين وأولياء الأمور** بنظام تسجيل دخول آمن يعتمد على **كود المتدرب أو رقم الهوية الوطنية + كلمة المرور**.
- لا يمكن الوصول لبطاقة الأداء وسجلات الحضور والغياب إلا بعد إدخال كلمة المرور الصحيحة الخاصة بكل مستخدم.
- عند تسجيل أي متدرب جديد، يتم تخصيص وحفظ كلمة مرور خاصة به فورياً.

### 3. حفظ جميع كلمات المرور في ملف منفصل باسم `password`
- تم إنشاء وتخصيص ملف منفصل تماماً باسم:
  ```
  password
  ```
  يحتوي على كافة كلمات المرور لجميع مستخدمي المنظومة (إدارة، مهندسي أقسام، ومتدربين).
- يُتاح قراءة وتحديث هذا الملف بصورة مستمرة عبر الخادم وإدارته مركزياً.

## 🛡️ أمان الـ IP والتنبيه الأمني المطلوب

عند محاولة دخول مهندس القسم من شبكة أو جهاز لا يتطابق عنوان الـ IP الخاص به مع الـ IP المخصص لورشة القسم، يمنع النظام الدخول ويظهر رسالة التنبيه الأمني الصارمة:
> **"عذراً، غير مصرح لك بالدخول من هذا الجهاز أو الشبكة (عنوان IP غير مطابق للقسم)"**

مع توفير شريط محاكاة عنوان الـ IP (`Simulate Lab IP`) في أعلى الشاشة لاختبار كافة الحالات بسهولة.

   - يمكن أيضاً فتح ملف [`index.html`](file:///j:/project_School2/index.html) في أي متصفح (Chrome أو Edge).
